# Thư mục Báo cáo Đồ án (Project Reports & Slides)

Thư mục này được chuẩn bị sẵn để lưu trữ hồ sơ bản mềm nộp tốt nghiệp theo quy định của Khoa Công nghệ Thông tin:

1. **Bản mềm báo cáo đồ án tốt nghiệp chính thức (PDF):**
   - Đặt tên file theo đúng cú pháp: `MSSV_HoTen_TenDeTai.pdf`
   - *Ví dụ:* `2351050199_LeVietQuoc_KnowledgeSharingPlatform.pdf`

2. **Slide trình chiếu bảo vệ đồ án (PDF):**
   - Đặt tên file: `slides.pdf` hoặc `MSSV_HoTen_Slides.pdf`
